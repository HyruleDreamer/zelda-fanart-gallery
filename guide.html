The keeper's guide

Your art.
Your stories. Simply shared.

Everything lives in your GitHub repository. There are no subscriptions, accounts for visitors, or upload services to manage.

This is a static website: it displays files but cannot save uploads. Use GitHub’s built-in Add file → Upload files tool to add your illustrations.

1. Upload your original

  1. Open your repository. Use the review branch while reviewing, and main after publication is approved.
  2. Open the appropriate folder, such as images/silent-world/. Choose Add file → Upload files, upload your original, and save.
  3. Use a descriptive filename, such as link-and-zelda-under-the-moon.png. The published gallery automatically uses it for a title and basic alt text.

GitHub prepares a 500-pixel thumbnail, adds the gallery entry, and publishes them together after publishing is enabled. Your original is unchanged. You do not need to resize images, edit metadata for every upload, understand Actions, or start a second deployment.

2. Add details if you want

For a custom title, chapter, description, or more precise alt text, edit data/gallery.js. Use the original filename and the correct story id. A custom entry replaces the automatic one for that file; it does not create a duplicate. Your uploaded artwork appears even without a custom entry. Describe the actual characters, setting, and action in alt text.

3. Publish later — once you approve

After reviewing and merging into main, open Settings → Pages and select GitHub Actions as the source. Then upload your first illustration or save a small description edit on main. This starts the first complete deployment. After that, ordinary uploads and metadata edits update the website automatically. The workflow never enables Pages itself and never deploys the review branch.

Your website will be https://HyruleDreamer.github.io/zelda-fanart-gallery/. Allow a few minutes for updates. Original files and generated previews are packaged together, so no second deployment is needed.

4. Place an image in AO3

  1. Open an illustration in your published gallery.
  2. Click Copy AO3 HTML.
  3. Switch the AO3 chapter editor to HTML, paste the code, and preview.
<img src="https://HyruleDreamer.github.io/zelda-fanart-gallery/images/silent-world/link-and-zelda-under-the-moon.png" alt="Link and Zelda beneath a full moon" style="max-width:100%;height:auto;">

The HTML already fits images to narrow screens without stretching. Both copy buttons use the original image URL, including meaningful alt text in the HTML. These links work only after the original is deployed.

The source ZIP does not contain generated previews or automatic entries. For an exact optional preview, the prepared website package is available in the workflow run’s github-pages download. See the README for details and troubleshooting.

Keep your links lasting

Once you embed an image, keep its filename, story folder, repository name, and GitHub username unchanged. Moving, deleting, or renaming any of these can break links in old chapters. To replace an image while preserving its URL, upload a new version with the same filename. GitHub may take a little time to refresh it.

Add another story

Add a new entry to the stories list in data/gallery.js, with a unique lowercase id and a title. Use that exact id for its image folder and illustration entries. The workflow creates the thumbnail folder automatically. Navigation updates automatically.

A note about privacy

Use HyruleDreamer for public credits and your confirmed GitHub noreply address for commits. Check your GitHub email privacy settings before saving changes. Remove personal details and location information from image metadata before uploading. Images in this public repository and website can be viewed and downloaded by anyone.
